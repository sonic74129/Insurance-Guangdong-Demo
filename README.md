# 安责险信息管理平台 · 公开演示

完整静态Demo：统一登录、保险业务、企业现场巡检、报告、风险和履约示例。
在部署站点或本机浏览器打开index.html，同一网址按可用窗口空间自动适配。
桌面左侧菜单／窄屏底部「全部功能」显示完整授权功能。「使用说明」在桌面为
右下角可移动窗口，窄屏为可返回原表单的整页帮助；未登录时入口位于页面末尾。
代码与功能共用不代表手机／电脑的本地进度自动同步。
演示密码为demo123；这不是生产认证，任何人均可下载所有运行代码及内置说明。

所有业务数据、证据、金额和评价均为合成示例；不是官方风险结论、保险条款、
真实服务履约或支付。机构名称只作演示标识，不代表真实业务记录、评分或背书。
不要输入真实客户资料、凭据或其他敏感信息。操作保存在当前浏览器本地，
不上传到服务器，不跨设备同步；本站不导入本机其他来源的存档。
场景恢复会覆盖明确选中的业务，接续现有进度时不要重置。

此仓库只含运行允许清单和最小Pages配置，没有私有源码历史、需求／招标原文、
开发测试或浏览器数据。release.json记录对应源提交及每个运行文件的SHA-256。
维护时从私有源的明确提交重新导出，不直接在此修改一份独立版本；
没有跨仓库自动同步、持续凭据、后端或真实上传功能。
